# Power Discipline Dashboard

Лёгкое автономное веб-приложение для учёта целей, ежедневных метрик, DBA и недельного ревью.

## Публикация через GitHub Pages

1. Загрузите все файлы этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. Сохраните настройки. GitHub покажет публичный адрес сайта.

## Локальный запуск

Откройте `index.html` в современном браузере.

## Данные

Данные сохраняются только в браузере пользователя (`localStorage`). Экспорт JSON доступен из интерфейса.

## Структура

- `index.html` — приложение, стили и логика в одном лёгком файле.
- `README.md` — инструкция.
- `.gitignore` — исключения для локальных и служебных файлов.

## Безопасность

Не добавляйте в репозиторий пароли, токены, персональные данные пользователей или резервные копии с чувствительными данными.
